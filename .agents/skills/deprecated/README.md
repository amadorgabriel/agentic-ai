# deprecated

Pasta de **arquivo**: skills que **não são mais usadas**.

## Para agentes

- **Não carregue** skills desta pasta.
- Não há `SKILL.md` aqui de propósito: os manifests foram renomeados para `ARCHIVED.md` para não entrarem na descoberta automática.
- Regra geral: ver [AGENTS.md](../../../AGENTS.md) na raiz do repo.

## Para humanos

O conteúdo permanece como referência histórica. Para reativar uma skill, mova-a para a categoria certa (`engineering`, `portfolio` ou `job-related`) e renomeie `ARCHIVED.md` de volta para `SKILL.md`.
