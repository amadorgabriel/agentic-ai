# Fase 0 — Ferramentas & Base

Pré-requisitos operacionais. Sessões curtas; marcar `solid` com fluência prática.

## Tópicos

| Tópico | Objetivo senior | Prática sugerida |
| --- | --- | --- |
| **Git** | branch, rebase, cherry-pick, resolve conflicts, conventional commits | Contribuir em repo real; simular conflict |
| **HTTP** | métodos, status codes, headers, caching, CORS, cookies vs tokens | Desenhar fluxo auth + API REST; debug com DevTools |
| **Terminal** | shell, pipes, env vars, curl, scripts básicos | Automatizar tarefa repetitiva do dia a dia |
| **Big-O** | complexidade tempo/espaço, trade-offs em collections | Analisar 3 snippets; escolher estrutura certa |

## Checkpoint (exemplos)

- Git: explicar rebase vs merge e quando usar cada um
- HTTP: o que acontece num POST com 401 vs 403
- Big-O: complexidade de lookup em HashMap vs lista
