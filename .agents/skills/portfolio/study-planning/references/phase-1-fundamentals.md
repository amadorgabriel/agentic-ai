# Fase 1 — Fundamentos

Base algorítmica e conceitual. Balancear teoria com exercícios curtos (LeetCode-style moderado).

## Tópicos

| Tópico | Objetivo senior | Prática sugerida |
| --- | --- | --- |
| **Estruturas de Dados** | arrays, lists, stacks, queues, hash maps, trees, graphs | Implementar ou usar APIs nativas; escolher SD para problema |
| **Algoritmos** | sorting, searching, BFS/DFS, two pointers, sliding window | 10–15 problemas médios (não grind infinito) |
| **Type systems** | estática vs dinâmica, generics, null safety, structural vs nominal | Comparar TS vs C#; artigos + snippets |
| **Encryption** | hashing vs encryption, TLS, at-rest vs in-transit, secrets básico | Configurar HTTPS; bcrypt/Argon2 em auth |
